# Don't Click The Button 🔴

A tiny, playful, slightly chaotic web game. There's a big red button that says not to click it.
She clicks it anyway. The button gets nervous, runs away, shrinks, multiplies into decoys,
and starts panicking in increasingly dramatic ways — until, after exactly 47 clicks, it all
pays off with a sweet finale.

## How to play

Just open `index.html` in any browser — no build step, no dependencies.

You can also host it for free with GitHub Pages: Settings → Pages → deploy from the
`main` branch (root), then share the link.

## Customize

- Her name is entered on the start screen and remembered for next time.
- Want to tweak the jokes, the click threshold, or the final message? Everything lives in
  `index.html` — look for the `messages` array and the `WIN_CLICKS` constant near the top
  of the `<script>` section.
